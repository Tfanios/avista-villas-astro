## How to open

1. Keep this entire folder intact. HTML files and the `images/` folder must stay together.
2. Open the HTML files in any browser (double-click).
3. The markdown deck opens in any text editor or directly in a markdown previewer.

## Quick start for the website build

1. Clone or replicate the Ardène Framer template structure in your project
2. Copy `avista-content-deck.md` and the `images/` folder into your project
3. Open `avista-content-deck.md`
4. Scroll to the bottom — copy "THE CODEX PROMPT" block
5. Paste into Codex (or Claude Code) and run
6. Iterate from the first pass

## A note on the logo

The HTML guides use the web font *Dancing Script* as a visual stand-in for the real Avista wordmark. For production, always use the original Avista logo file (SVG or vector). The brand rules in Volume I · Section 05 apply to the actual mark.
